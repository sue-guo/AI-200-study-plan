# AI-200 考试计划

目标认证：Microsoft Certified: Azure AI Cloud Developer Associate / Exam AI-200

## 当前学习方向

从 AZ-204 转向 Azure AI 方向，主线选择 AI-200。学习重点不是单纯 AI 理论，而是 Azure 云开发能力、AI 数据服务、容器化部署、服务集成、安全、监控和故障排查。

## 官方考试模块

- Develop containerized solutions on Azure: 20-25%
- Develop AI solutions using Azure data management services: 25-30%
- Connect to and consume Azure services: 20-25%
- Secure, monitor, and troubleshoot Azure solutions: 20-25%

## 每日固定节奏

- 学官方文档或 Microsoft Learn 45-60 分钟
- 动手实践 45-60 分钟
- 记录 5-10 个考点或坑点
- 复盘错题、弱项或昨天没掌握的内容

## 最终实战项目

做一个 AI 文档问答服务，建议包含：

- Python FastAPI
- Azure OpenAI 或 Microsoft Foundry 模型调用
- Cosmos DB 或 PostgreSQL + pgvector 存 embeddings
- Redis cache
- Service Bus 异步任务
- Azure Container Apps 部署
- Key Vault 管理 secrets
- App Configuration 管理配置
- Application Insights + OpenTelemetry 监控
- KQL 故障排查查询
